# WOW Astro — Private Creator Beta

Invite-only, no-data static prototype for independent creator feedback.

- No accounts, cookies, analytics, forms or server-side collection.
- No birth date, birth time or location.
- No payment or checkout.
- No claim that the automated copy is Sol Vartan's personal interpretation.
- Feedback is generated locally for copy/paste.
- `noindex` requested on every page.
- The front-end access code is friction, not strong authentication.

Deployed with GitHub Pages from `.github/workflows/pages.yml`.
